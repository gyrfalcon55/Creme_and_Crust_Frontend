# Crème & Crust

Premium Indian artisan bakery website built with React, Vite, Tailwind CSS, and Lucide React.

## Requirements
- Node.js 18+ recommended
- npm

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Project structure

```text
creme-crust/
├── index.html
├── package.json
├── vite.config.js
├── postcss.config.js
├── tailwind.config.js
├── README.md
└── src/
    ├── main.jsx
    └── index.css
```
